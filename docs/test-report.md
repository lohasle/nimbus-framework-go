# 测试报告

## 范围

本报告覆盖 Nimbus Framework Go 底座的后端回归、前端静态质量门禁，以及登录过期与并发 401 的专项验证。详细测试分层见 [测试策略](testing-strategy.md)，认证设计见 [架构说明](architecture.md)。

## 401 专项验收

| 场景                     | 预期结果                                                 |
| ------------------------ | -------------------------------------------------------- |
| 多个接口同时返回 401     | 只发起一次 Refresh Token 请求，不出现多个 401 弹窗       |
| 刷新成功                 | 各原请求携带新 Access Token 重试一次，停留在原页面       |
| Refresh Token 缺失或失效 | 立即清理令牌、用户缓存和动态路由，只提示一次并跳转登录页 |
| 重试后仍返回 401         | 不再刷新或重放请求，执行一次统一退登                     |
| 多浏览器标签页同时过期   | 使用同一租户的 Web Lock 串行刷新，后续标签复用已更新令牌 |
| 登录等公开接口返回 401   | 显示接口自身错误，不误判为已有会话过期                   |
